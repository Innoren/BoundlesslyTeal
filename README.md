# BoundlesslyTeal + SiteSift

This repository contains:

- The Boundlessly Teal Coaching static site (`index.html` and related assets)
- **[SiteSift](./sitesift)** — a Next.js app that finds reputable Google businesses with no website and designs a presentable site for them in one click

## Run SiteSift

```bash
cd sitesift
npm install
npm run dev
```

See [`sitesift/README.md`](./sitesift/README.md) for Google Places setup.
